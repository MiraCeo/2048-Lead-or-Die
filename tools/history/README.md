# tools/history —— 一次性变更脚本（已执行完）

这些脚本是**变更历史**，不是流水线的一部分。请不要在构建或测试里引用它们。

它们的价值在于：每个脚本记录了那一次改动的**精确替换文本、锚点与理由**，
是“为什么这么改”的一手证据。改动溯源时按文件名里的序号（step1…step16）顺序读即可。

| 前缀 | 内容 |
| --- | --- |
| `step1…step16` | 功能与界面改动（含配套的测试同步脚本 `*b_tests` / `*c`） |
| `doc_sync*` / `doc_chinese` / `doc_finish` | 项目文档的历次更新 |
| `handover_doc*` | 交接文档的状态对照与执行前必读 |

当前工具链、测试与诊断脚本在上一级 `tools/` 目录。完整说明见 项目文档.md §14.3 / §14.4。
